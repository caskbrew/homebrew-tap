# caskbrew/tap

Homebrew tap for caskbrew apps.

```
brew install --cask caskbrew/tap/tradestickies
```

| Cask | App |
|---|---|
| `tradestickies` | [TradeStickies](https://github.com/caskbrew/TradeStickies): floating sticker windows with live PnL for crypto trades |

Update: `brew update && brew upgrade --cask tradestickies`

Remove: `brew uninstall --zap --cask tradestickies`
